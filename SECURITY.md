# Security

ReviewFilm21 saat ini menggunakan hosting static GitHub Pages.

## Catatan keamanan

- Jangan menyimpan API key rahasia di frontend.
- Kredensial server-side sebaiknya hanya digunakan pada backend yang benar-benar aktif.
- Provider video dan sumber eksternal mengikuti kebijakan masing-masing.
- Laporkan masalah keamanan melalui mekanisme issue/private contact yang tersedia pada repository.
